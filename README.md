 Responsive Bootstrap Website

 Project Overview

This project is a fully responsive website created using **HTML, CSS, JavaScript, and Bootstrap 5**.
It contains a navigation bar, hero section, services section, about section, contact form, and footer.

The website is designed to work smoothly on desktop, tablet, and mobile devices.

 Features

* Responsive Navigation Bar
* Hero Section with Background Image
* Services Section with Hover Effects
* About Us Section
* Contact Form
* Mobile-Friendly Design
* Bootstrap 5 Framework
* Simple JavaScript Interaction

 Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
